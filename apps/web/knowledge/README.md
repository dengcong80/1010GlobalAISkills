# BeeTrust knowledge package

This directory is the public, versioned knowledge layer used by the seven Skills. Each rule records a source ID, a decision branch, a limitation and a verification case. The package is a demonstrator: it does not contain private enterprise SOPs or a certificate authority.

The mapping is deliberately inspectable:

`public source -> distilled rule -> TypeScript branch -> self-test -> release gate`

Before a real shipment, an authorised exporter and broker must refresh the source snapshots and replace synthetic evidence with accredited records.
